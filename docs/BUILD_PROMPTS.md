# Phased build prompts

1. **Demand concierge:** Build a manual order ledger and landing CTA for a $25 refundable reservation. Instrument view → photo checklist → complete set → preview → deposit. No reconstruction automation.
2. **Private capture:** Add authenticated signed uploads, MIME/signature checks, EXIF stripping, explicit retention, deletion receipts, and quality metrics. Test nil, empty, oversized, corrupt, duplicate, and interrupted uploads.
3. **Preview worker:** Put one reconstruction provider behind an adapter with idempotent jobs, timeouts, retry limits, circuit breaking, cost caps, and a deterministic fallback scene. Expose progress and named failure states.
4. **Gift builder:** Implement one fixed escape template, three anchored clue stops, a reviewer console, buyer approval, and accessibility checks. Store renderer/model versions for reproducibility.
5. **Fulfillment:** Add capacity-aware due dates, payment, refund rules, expiring delivery links, deletion jobs, analytics, alerting, and a support runbook. Only then test party and occasion expansion.
